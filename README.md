## 🛠 Tech Stack (웹사이트 아키텍처)

이 프로젝트의 웹사이트들은 검색엔진 최적화(SEO)와 압도적인 로딩 속도를 위해 아래와 같은 기술 스택으로 구축되었습니다.

*   **Core**: Node.js 기반 커스텀 정적 사이트 생성기 (SSG)
*   **SEO**: 동적 메타태그 주입 및 로컬 비즈니스용 `JSON-LD` (EntertainmentBusiness) 자동 생성
*   **Deployment**: Cloudflare Pages를 통한 전 세계 Edge 네트워크 자동 배포 (CI/CD)
*   **Performance**: 이미지 지연 로딩(Lazy Loading) 및 리소스 최적화
